# Лендинг «ЛИНИЯ»

Статический одностраничный сайт ремонтной компании «ЛИНИЯ» (Кисловодск и
Кавказские Минеральные Воды). Собирается в обычные HTML/CSS/JS и хостится на
GitHub Pages: без сервера, базы данных, админки и pm2.

- **Сайт:** https://liniakmw.ru
- **Стек:** Next.js 15 (App Router) + React 19, статический экспорт (`output: "export"`)
- **Сборка:** `npm run build` → папка `out/` — это и есть готовый сайт
- **Контент:** один файл [`content/site.ts`](content/site.ts)

---

## 1. Локальный запуск

Нужен Node.js 22 или новее.

```bash
npm ci          # один раз
npm run dev     # http://localhost:3000 — разработка с горячей перезагрузкой
```

Проверить именно статическую сборку (так сайт будет выглядеть на хостинге):

```bash
npm run build      # создаёт out/
npm run preview    # http://127.0.0.1:4173 — сервер из папки out/
```

Дополнительно:

```bash
npm run typecheck  # проверка типов
npm run lint       # ESLint
npm test           # тесты калькулятора
```

## 2. Как менять контент

Всё содержимое лежит в [`content/site.ts`](content/site.ts):

| Что | Где в файле |
|---|---|
| Телефон, почта, город, часы работы | `settings` |
| Цены калькулятора, ₽/м² | `settings.calc_cosmetic` / `calc_capital` / `calc_designer` |
| Услуги: название, описание, состав, этапы | `services` |
| Проекты и фотографии | `projects` (первое фото — обложка) |
| Домен сайта | `siteUrl` |
| Куда уходят заявки | `formConfig` |

Фотографии лежат в `public/assets/img/`. Чтобы добавить новую: положите файл
`.webp` в эту папку и укажите путь `/assets/img/имя-файла.webp` в `projects`.

После правок пересоберите сайт — GitHub Actions сделает это сам при push.

## 3. Заявки без сервера

Форма работает всегда, но есть два режима.

**По умолчанию — WhatsApp.** Форма проверяет поля, собирает текст заявки и
показывает кнопку «Отправить в WhatsApp» с уже заполненным сообщением. Номер
берётся из `settings.phone`. Ничего настраивать не нужно, регистраций нет.

**Автоматически на почту — Web3Forms** (бесплатно, 250 заявок в месяц):

1. Зайдите на [web3forms.com](https://web3forms.com), укажите почту — придёт
   access key.
2. В `content/site.ts` впишите:

```ts
export const formConfig = {
  formEndpoint: "https://api.web3forms.com/submit",
  formAccessKey: "ваш-ключ",
  whatsapp: "",
};
```

После этого заявки будут приходить на почту, а форма покажет «Заявка отправлена».

## 4. Публикация на GitHub Pages

### Шаг 1. Репозиторий

Создайте на GitHub пустой репозиторий (например, `linia`) и загрузите в него
файлы проекта (без `node_modules`, `.next`, `out` — они в `.gitignore`).
Проще всего через GitHub Desktop: Add local repository → Publish.

Если репозиторий приватный, GitHub Pages доступен только на платном тарифе —
для бесплатного сделайте репозиторий публичным. Секретов в проекте нет.

### Шаг 2. Включить Pages

В репозитории: **Settings → Pages → Build and deployment → Source:
GitHub Actions**. Больше ничего выбирать не нужно.

### Шаг 3. Push

Любой push в ветку `main` запускает `.github/workflows/pages.yml`: установка
зависимостей, `npm run build`, публикация `out/`. Через минуту сайт доступен по
адресу `https://<логин>.github.io/<репозиторий>/`.

Этот адрес — технический. Постоянный адрес даёт свой домен (ниже).

> Пока домен не подключён, страница по адресу `/<репозиторий>/` может
> открыться без стилей и картинок: ссылки на файлы сайта абсолютные (`/_next/`,
> `/assets/`) и запрашиваются с корня домена. Это нормально — подключите домен
> по разделу 5, и сайт заработает как надо. Для проверки вёрстки до этого
> используйте `npm run preview`.

### Вариант без сборки (если не хотите Actions)

Можно загрузить в репозиторий уже собранный сайт: выполните `npm run build` и
скопируйте **содержимое** `out/` в корень репозитория (включая `.nojekyll`).
Затем **Settings → Pages → Source: Deploy from a branch → main / (root)**.
Минус: после каждой правки контента нужно пересобирать и заново загружать файлы.

## 5. Домен и HTTPS

Домен `liniakmw.ru` уже есть — его нужно перенаправить с сервера на GitHub Pages.
GitHub выпускает SSL-сертификат сам и бесплатно (Let's Encrypt), покупать
ничего не надо.

### DNS

В панели регистратора домена:

| Тип | Имя | Значение |
|---|---|---|
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |
| CNAME | `www` | `<логин>.github.io.` |

Старые A-записи на IP сервера удалите. Обновление DNS занимает от нескольких
минут до пары часов.

### Привязка в GitHub

**Settings → Pages → Custom domain** → `liniakmw.ru` → Save. Когда DNS
обновится, появится галочка и станет доступна опция **Enforce HTTPS** —
включите её.

Файл `CNAME` создаётся автоматически при сборке из `siteUrl` в
`content/site.ts`, вручную его добавлять не нужно.

## 6. Структура проекта

```

lib/                 калькулятор, отправка заявки, склонения, доступ к контенту

.github/workflows/   автодеплой на GitHub Pages
```

## 7. Что изменилось по сравнению с серверной версией

Серверная версия с SQLite, админкой `/admin` и API удалена. Убраны: база
данных, вход администратора, загрузка файлов, Telegram-уведомления. Правки
контента теперь делаются в `content/site.ts` и публикуются через git — это
проще и не требует обслуживания сервера.

Проверено: сборка (`npm run build`), типы (`tsc --noEmit`), тесты калькулятора,
десктоп и мобильная вёрстка, форма заявки, 404-страница, sitemap и robots.
